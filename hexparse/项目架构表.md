# HexMod 项目架构表

> 本仓库是 **Hex Casting** 的 Minecraft 26.1.2 / Fabric 移植版，并内置 MoreIotas、HexDebug、HexCassettes 等内容。
> `settings.gradle` 只纳入 `Common` 与 `Fabric` 两个构建模块。下表按“源码目录 → 职责 → 关键类”整理。

## 1. 顶层模块

| 目录 | 角色 | 主要内容 | 参与构建 |
| --- | --- | --- | --- |
| `Common/` | 跨平台核心 | API、通用实现、客户端逻辑、数据生成、mixin | 是 |
| `Fabric/` | Fabric 平台层 | 模组入口、注册、网络、存储、平台 mixin、内置附属模组 | 是 |
| `Forge/` | 旧平台实现 | 保留源码，未在 `settings.gradle` 中 include | 否 |
| `doc/` | 文档站 | hexdoc 配置与生成资源 | 否 |
| `hexparse/` | 咒术资料 | 图案速查表、咒术列表 | 否 |
| `libs/` | 本地依赖 | `flatDir` 仓库中的 jar | 否 |
| `art/` | 美术源文件 | 贴图、模型等源资源 | 否 |

## 3. 一次施法的执行链路

```text
绘制图案 → PatternShapeMatcher → HexPattern（角度签名）
        → PatternRegistryManifest 查表 → ActionRegistryEntry
        → CastingVM 执行 → Action 修改 CastingImage 栈
        → CastingEnvironment + 媒体 → 世界副作用 / Mishap
```

| 阶段 | 组件 | 关键位置 | 说明 |
| --- | --- | --- | --- |
| 1. 图案识别 | `PatternShapeMatcher` | `client/PatternShapeMatcher.java` | 把绘制出的笔画序列还原成 `HexPattern` |
| 2. 图案查表 | `PatternRegistryManifest` | `common/casting/PatternRegistryManifest.java` | 启动时把角度签名缓存为 O(1) 查表 |
| 3. 动作定位 | `ActionRegistryEntry` | `api/casting/ActionRegistryEntry.java` | 保存图案、动作与注册 id |
| 4. 虚拟机执行 | `CastingVM` | `api/casting/eval/vm/CastingVM.kt` | 维护栈、括号、延续与逐帧执行 |
| 5. 动作结算 | `Action` 子类 | `common/casting/actions/` | 取参、改栈、产生法术效果 |
| 6. 环境与媒体 | `CastingEnvironment`、`MediaHelper` | `api/casting/eval/`、`api/utils/MediaHelper.kt` | 施法者/法器/施法圈环境，扣除媒体 |
| 7. 失败处理 | `Mishap` | `api/casting/mishaps/` | 类型、位置、实体等非法时转为失误提示 |

## 4. 图案动作类型

| 基类 | 取参方式 | 媒体消耗 | 典型图案 |
| --- | --- | --- | --- |
| `Action` | 自行读写栈（最灵活） | 自行处理 | `escape`、`open_paren`、`last_n_list` |
| `SpellAction` | `argc` + `args[i]` | 由实现决定 | `break_block`、`place_block`、`explode` |
| `ConstMediaAction` | `argc` + `args[i]` | 构造时固定 | `get_entity`、`raycast`、`compare_entity` |
| `OperationAction` | 交给算术引擎按类型分派 | 无 | `add`、`index_of`、`construct` |

> 参数顺序：`args[0]` 是最先压栈、位于参数组最底部的那个；对应速查表“输入”列最左边的参数。

## 5. iota 类型与 hexparse 写法

| 类型 | 实现类 | hexparse 写法示例 |
| --- | --- | --- |
| 空 | `NullIota` | `null` |
| 数字 | `DoubleIota` | `1.5` |
| 布尔 | `BooleanIota` | `true` / `false` |
| 向量 | `Vec3Iota` | `vec_1_2_3` |
| 列表 | `ListIota` | `[ 1 2 3 ]` |
| 字符串 | `StringIota`（MoreIotas） | `str_文本` 或 `"文本"` |
| 图案 | `PatternIota` | `_qaq`、掩码图案 |
| 实体 | `EntityIota` | `entity_<UUID>`、`self` |
| 实体类型 | `EntityTypeIota` | `type/entity_minecraft:zombie` |
| 物品类型 | `ItemTypeIota` | `type/item_minecraft:stone` |
| 方块类型 | `ItemTypeIota` | `type/block_minecraft:stone` |
| iota 类型 | `IotaTypeIota` | `type_hexcasting:double` |
| 矩阵 | MoreIotas 矩阵 iota | `mat_...` / `matrix_...` |
| 垃圾 | `GarbageIota` | `garbage` |
| 延续 | `ContinuationIota` | 运行时产生，不能直接写字面量 |

> `num_<n>` 在 hexparse 中表示“数字 n 的图案”（PatternIota），执行该图案才会压入数字；直接写 `1.5` 则是 `DoubleIota`。

## 6. 算术重载体系

| 算术表 | 类型 | 覆盖图案 |
| --- | --- | --- |
| `DoubleArithmetic` | 数字 | `add`、`sub`、`mul`、`div`、`abs`、`pow`、`floor`、`ceil`、`sin`、`cos`、`tan`、`arcsin`、`arccos`、`arctan`、`arctan2`、`logarithm`、`modulo` |
| `Vec3Arithmetic` | 向量 | `add`、`sub`、`mul`、`div`、`abs`、`pow`、`floor`、`ceil`、`modulo`、`construct_vec`、`deconstruct_vec` |
| `ListArithmetic` | 列表 | `add`、`abs`、`index`、`slice`、`replace`、`append`、`unappend`、`index_of`、`remove_from`、`reverse`、`construct`、`deconstruct` |
| `BoolArithmetic` | 布尔 | `and`、`or`、`xor`、`not`、`abs`、`greater`、`less`、`greater_eq`、`less_eq` |
| `ListSetArithmetic` | 列表（集合语义） | `and`、`or`、`xor`、`unique` |
| `BitwiseSetArithmetic` | 数字（按位） | `and`、`or`、`xor`、`not` |
| `StringArithmetic` | 字符串 | `add`、`mul`、`abs`、`index`、`slice`、`reverse`、`index_of`、`remove_from`、`replace`、`unique` |
| `MatrixArithmetic` | 矩阵 | `add`、`sub`、`mul`、`div`、`abs`、`pow`、`floor`、`ceil`、`reverse`（转置）、`altmul`、`altdiv`、`altpow` |
| `ItemArithmetic` | 物品 | `abs`、`type/to_item`、`item/make` |
