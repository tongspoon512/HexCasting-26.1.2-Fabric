# 三日凌空 · 设计文档

> 状态：已实现（天顶法术）。图案 `wdwwwdwwwdwewdwdw`，起始方向 `WEST`，输入一个火之领域。

## 1. 设计原则

Hex Casting 的理念是“让一切成为可能，而不是让其更简单”。因此本法术不是更大的爆炸，而是**把一小片白昼搬到任意位置**：

- 它不直接杀死普通生物，也不破坏方块；
- 它改变区域内的环境规则（光照、温度、作物生长、怪物灼烧）；
- 它让地下农场、融冰取水、烘干海绵、日光温室成为可能，而不是跳过这些玩法。

## 2. 施法参数

| 项目 | 值 |
| --- | --- |
| 注册 id | `hexcasting:three_suns_adrift` |
| 图案 | `wdwwwdwwwdwewdwdw`，起始 `WEST` |
| 输入 | `area` 火之领域（三个角即三颗太阳的锚点） |
| 输出 | 无 |
| 类别 | 天顶法术（`requires_enlightenment`、`can_start_enlighten`、`per_world_pattern`，图案随世界随机） |
| 施法者 | 必须有 `castingEntity`；法术环与分析机不可施放 |
| 区域 | 火之领域三个角在水平面投影出的三角形；Y 从最低点 −8 到最高点 +16 |
| 持续 | 24000 tick（20 分钟） |
| 媒质 | 1 充能紫水晶（10 粉）+ 每 4 格² 1 粉；30 格² ≈ 18 粉 |
| 上限 | 面积 < 1 格² 或 > 400 格² 触发失误 |
| 重叠 | 同一维度重新施放会替换旧场，不叠加 |

## 3. 三颗太阳

- 每颗太阳直接落在对应顶点上，只用粒子与光柱表现，不写入任何光源方块，因此退出世界时不会留下残留方块。
- 作用范围是整个火之领域（三角形顶面向下 10 格的柱体）；某颗太阳熄灭后，只有离它最近的区域会变暗。
- 每秒从太阳向下方发射光柱粒子；光柱不作为实体存在，不破坏方块。
- 视觉使用 `END_ROD` 与 `SMALL_FLAME`，不新增粒子类型。

## 4. 日照效果（每 20 tick 结算）

只有同时满足以下条件的方块/实体才受影响：

1. 位于火之领域范围内；
2. 所属太阳仍存活；
3. 方块位于所属太阳向下的第一层非空气方块上；更上层的方块会替它挡住阳光。

效果：

| 对象 | 效果 |
| --- | --- |
| 雪层 | 每次减少一层，最后一层移除 |
| 冰 / 霜冰 | 变为水 |
| 细雪 | 移除 |
| 湿海绵 | 变为干海绵 |
| 可催生方块（`BonemealableBlock`） | 每秒 20% 概率执行一次 `randomTick`，加速生长而非瞬间骨粉 |
| 敌对生物（实现 `Enemy`，如僵尸、末影人） | 每秒着火 3 秒，并受到 6 点魔法伤害 |
| 其他生物（玩家、动物等） | 无伤害、无状态效果 |

## 5. 反制

- **水 / 细雪**：从太阳向下的光柱最先碰到水或细雪时，该太阳立即熄灭。
- **雨天**：每 5 秒有 25% 概率熄灭一颗仍存活的太阳。
- **阴影**：屋顶、隧道、树叶会挡住实体到太阳的连线；方块只有 `canSeeSky` 时才受热。
- **全部熄灭**：法术提前结束，媒质不返还，不产生爆炸。

## 7. 验收清单

- [ ] 传入火之领域后，三颗太阳出现在领域的三个角上，并落下光柱；传入其他领域触发失误。
- [ ] 三角形与向下 10 格内的雪、冰、细雪、湿海绵在数秒内变化；屋顶下不变。
- [ ] 敌对生物（僵尸、末影人等）在直射光下持续着火并每秒受到 6 点伤害，玩家与动物不掉血。
- [ ] 在某一颗太阳下方放水，只有该太阳熄灭，离它最近的区域失效。
- [ ] 雨天会逐渐熄灭太阳；20 分钟后自动结束且无爆炸。
- [ ] 面积小于 1 或大于 400 时出现对应失误；法术环/分析机无法施放。
- [ ] 重新施放后旧场消失，不出现重复光柱；退出并重进世界后没有残留光源方块。
